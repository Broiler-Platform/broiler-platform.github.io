The apps

Three apps, one platform underneath

A browser, a word processor and a code editor. They share a toolkit, a renderer and one way of handling files — so they look alike, behave alike, and run on the same set of machines.

Broiler Browser

Type an address, follow links, fill in forms, keep favourites. It renders real pages with an engine written from scratch — no Chromium inside.

WindowsLinuxAndroid

Broiler Writer

Write, format and save documents — Word, RTF, HTML, Markdown — with a reveal-codes view that shows exactly what formatting is where.

Broiler Code

Edit C#, see errors as you type, press Build. Plus a review workspace that tracks what a person has actually read, file by file.

All three build and run, and continuous testing keeps them building — but no signed, installable release has been published, because the review and packaging work that should come first is not finished. If you can run a build, you can run all three today. What that means in practice →

What they have in common

The same window, everywhere

Broiler draws its own controls, menus and title bars rather than borrowing the system's. An app looks and behaves the same on Windows, Linux and Android.

Real system windows where it counts

On Windows, dialogs like Open and Save are genuine top-level windows: you can drag one to a second monitor, and closing it never closes the app.

No account, ever

None of the three has a sign-in, a profile or telemetry. On Android only the Browser may use the network at all, and unencrypted connections are off.

Keyboard, mouse, pen and touch

Input is handled by one shared layer, including on-screen keyboards and international text input on Android.

Light and dark

The controls carry a theme system, so the apps follow the look you have chosen rather than fighting it.

Small downloads — eventually

The desktop Writer compiles to a single 9.2 MB file that runs with no .NET installed. That is the shape releases will take.
