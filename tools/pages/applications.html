The apps

Five apps, one platform underneath

A browser, a word processor, a viewer, a code editor and a mail app. They share a toolkit, a renderer and one way of handling files — so they look alike and behave alike, wherever each of them runs.

Broiler Browser

Type an address, follow links, fill in forms, keep favourites. It renders real pages with an engine written from scratch — no Chromium inside.

What they have in common

The same window, everywhere

Broiler draws its own controls, menus and title bars rather than borrowing the system's. An app looks and behaves the same on every system it runs on.

Real system windows where it counts

On Windows, dialogs like Open, Save and About are genuine top-level windows: you can drag one to a second monitor, and closing it never closes the app.

No Broiler account, ever

None of the apps has a Broiler sign-in or telemetry. Mail signs in to your own mail server only. On Android only the Browser may use the network at all, and unencrypted connections are off.

Keyboard, mouse, pen and touch

Input is handled by one shared layer, including on-screen keyboards and international text input on Android.

Light and dark

The controls carry a theme system, so the apps follow the look you have chosen rather than fighting it.

Small downloads

The Writer's and Plate's desktop previews are each a single file that runs with no .NET installed — about 5 MB zipped. The Browser's preview is much bigger, about 47 MB zipped, because its JavaScript engine cannot be compiled that way yet.

"Emulator-tested" means it builds and runs on an emulated Android 16 device. Nobody has verified either app on a physical phone yet — even though the Writer's preview now includes an Android package you can install. "Paused" means the Writer's web version is not being built while it is moved onto the platform's new packages; no preview includes it. macOS is not supported and is not close.

Further out

Broiler Fond — "Finance on Demand" — is a planned home-banking app: one program on your own computer that talks directly to your own bank accounts, with nothing passing through the project. It is at the stage of groundwork only. Its own description is blunt: it has no bank connection, no handling of credentials, no payments and no user interface yet, and it is not a registered banking product. Its repository tracks the plan.
