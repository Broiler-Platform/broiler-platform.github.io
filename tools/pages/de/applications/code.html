Broiler Code

Syntaxhervorhebung, laufende Fehlerprüfung und Builds für C# auf .NET 10. Ein eigener Arbeitsbereich dokumentiert die menschliche Prüfung einzelner Quelldateien.

C# bearbeiten

Plattformen: Windows und Linux

C# auf .NET 10

Code nutzt normale Projektdateien und bietet Syntaxhervorhebung, laufende Fehlerprüfung und einen Build-Befehl. Der Vorschauumfang ist C# auf .NET 10; es gibt kein eigenes Broiler-Projektformat.

Menschliche Code-Prüfung nachvollziehen

Ein Arbeitsbereich hält pro Quelldatei fest, was tatsächlich gelesen wurde. Review-Zustände beziehen sich auf einen Fingerabdruck des konkreten Inhalts. Eine geänderte Datei kann dadurch nicht einfach eine alte Freigabe übernehmen.

Selbst bauen

Code ist eine frühe Vorschau. Hinweise zum Bauen und zum Review-Arbeitsbereich stehen in der technischen Dokumentation (Englisch).

Vor dem Testen

Eine frühe Vorschau

Diese Software ist zum Ausprobieren und Testen gedacht, nicht für den produktiven Alltag. Menschliche Code-Prüfungen sind noch offen. Verwende Kopien wichtiger Dateien und öffne nur vertrauenswürdige Inhalte.
