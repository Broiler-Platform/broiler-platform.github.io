App

Broiler Mail

A small, straightforward mail app for one account, built on the same toolkit as the other Broiler apps. It receives and reads mail today; sending is the version being built now.

Windows In development

What it does

The project builds Mail in numbered versions, each with one clear outcome. The first — "I can configure one account and read incoming mail" — is implemented.

  • Set up one mail account that uses IMAP, with your provider's settings
  • Keep its password in Windows' own Credential Manager, not in a file
  • Test the connection before you rely on it
  • Receive mail into your inbox, a page at a time, and read it as plain text
  • Leave messages on the server exactly as they were — reading marks nothing
  • Light, dark or system theme, a keyboard shortcut for every tab, and clipboard support

Being built now: sending

The second version adds writing mail: a plain-text editor with Reply, Reply all and Forward, sending over an encrypted connection to your provider, and a draft that is saved on your machine and comes back if the app closes. That code has landed, but it has only been checked against test servers the project controls — not against a real mail provider yet.

What it doesn't do yet

  • Sign in to providers that only allow browser-based (OAuth) sign-in — a password or app password is the only option
  • Open or save attachments
  • Keep your mail — messages are held in memory and must be received again after you restart it
  • Folders other than the inbox, search, or offline reading
  • More than one account
  • Show formatted (HTML) email
  • Run on Linux or anywhere but Windows

These are deliberate limits of the early versions, not oversights: multiple accounts, attachments, folders, search, offline use and Linux are each a later version on the Mail roadmap, which gives no dates.

Your mail and your password

  • Mail talks only to the mail server you configure. There is no Broiler account and nothing goes to the project.
  • Certificate errors cannot be clicked away, and a connection set up to be encrypted never falls back to sending your password in the clear.
  • Your password is kept in Windows Credential Manager, and changing the server details invalidates it.

Not tested with your provider

The project states that no public mail provider is claimed as certified: testing against a live provider has been deferred. No person has reviewed the code yet either — its review record reads pending, 0 of 420 relevant units reviewed.

Getting it

No download

Nothing has been released. The repository can produce a self-contained Windows build on a developer's machine, but none has been published, and it has no automated build or signing yet. If you can build .NET software, the repository explains how — including a demo mode that shows the whole app with made-up messages and no account at all.

For developers

A platform-neutral core with a Windows host on Broiler.UI and the Direct2D backend, taking every Broiler component from nuget.org. Unlike the rest of the platform it uses one third-party library, MailKit, for the mail protocols.
