App

Broiler Plate

A viewer. It opens a document or a picture and shows it — nothing else. The read-only half of the Writer: the same file readers and the same page, with editing and saving taken out.

Windows Preview download

What it opens

KindFormats
DocumentsRTF, DOCX, HTML, Markdown and PDF
PicturesPNG, JPEG, GIF, BMP, TIFF and WebP

A document looks the same here as it does in the Writer, because it is drawn by the same control. Plate decides what a file is by looking at its contents first and its name last, so a picture saved with the wrong extension still opens as a picture.

What it does

  • Open a file from the toolbar, the File menu or Ctrl+O
  • Zoom from 25 % to 400 % — the same steps as the Writer
  • Fit a picture to the window, which is where every picture starts
  • Select and copy text from a document
  • If a file can't be opened, keep showing what was already there, and say why
  • Notes on anything the file's reader had to approximate

What it doesn't do

  • Edit or save anything — that is the Writer's job
  • Open more than one file at a time
  • Move around a picture that is bigger than the window — it is cut off at the edges, with nothing to scroll or pan it yet
  • Play sound or video
  • Browse or manage your files
  • Run anywhere but Windows

The project lists the missing pieces on its roadmap without dates.

Opening a file is not risk-free

Reading a document means parsing whatever is inside it, and the code that does that has had no fuzzing, no dependency scan and no independent security audit. The project says plainly that Plate is meant "for evaluation, testing and contribution — not production, security-critical or safety-critical use". Open files you trust.

Getting it

A Windows preview you can download

Broiler Plate 0.1.0-preview.2 was published on 22 September 2026 as a GitHub pre-release, "a preview build for evaluation and testing, not for production use".

  • One zip for 64-bit Windows, about 4.4 MB, holding a single program file. Unzip it and run it — there is nothing to install.
  • It is not code-signed, so Windows SmartScreen may ask before the first start.
  • No person has reviewed its code yet: its review record reads pending, 0 of 248 relevant units reviewed.

For developers

One Windows head over a shared core, taking the document codecs, the UI toolkit and the graphics stack as versioned NuGet packages. CI builds, tests and publishes a NativeAOT executable, then starts it to check it stays up.
