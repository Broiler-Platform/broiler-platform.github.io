App

Broiler Writer

A word processor that opens the documents you already have, formats them the way you expect, and can show you exactly what formatting is where.

Windows Linux Android · emulator-tested In a browser Early preview

The files it opens

FormatOpenSave
Word document .docxYesYesText, formatting and lists. Tables are read and their text kept, but flattened into paragraphs — the app tells you when that happens rather than losing them quietly.
Rich Text .rtfYesYesThe best-documented format here; the reader never fails on a malformed file.
HTMLYesYesUses the same HTML engine as the browser.
MarkdownYesYesA safe CommonMark-style subset.
PDFRead only—Windows and Linux only, and text only. Deliberately switched off elsewhere until it has been reviewed further.
OpenDocument .odt——The platform can read and write it, but the Writer does not register it yet.

What it does

  • New, open, save and save-as
  • Bold, italic, underline, strikethrough
  • Choose fonts and sizes through a font dialog
  • Text and background colour
  • Align left, centre, right
  • Bullet and numbered lists
  • Indent and outdent
  • Clear formatting
  • Insert pictures
  • Undo and redo
  • Cut, copy, paste, select all
  • A document toolbar and a status line

Reveal codes

The feature old WordPerfect users still miss. Turn on Formatting Codes and a second pane shows the document as a stream of tokens — where bold starts and stops, where a paragraph break really is, which tab is doing the indenting — kept in sync with the page as you type.

When a document formats strangely, this is the difference between guessing and looking.

You can select a code and delete it, which is often the fastest way to fix a document that came from somewhere else and behaves oddly.

Dialogs that behave like real windows

On Windows, Open, Save As, Insert Picture and Font are genuine top-level windows. You can drag one onto a second monitor, the window manager orders it like any other window, and closing a dialog never closes the Writer.

On Linux, Android and in the browser they stay inside the main window instead. That is the documented fallback, not a bug: the app asks the system whether it can have a real window, and does the sensible thing when it can't.

What it doesn't do yet

  • Tables — text inside them is read, but you cannot create or edit one
  • Footnotes, endnotes, headers and footers
  • Track changes or comments
  • Spell check or grammar check
  • Mail merge
  • Styles as a managed, reusable set
  • Printing
  • Saving to PDF

On each platform

PlatformWhat you get
Windows The most complete version: hardware-accelerated drawing, real system windows for dialogs, and PDF reading. Compiles to a single 9.2 MB file that runs with no .NET installed.
Linux Same features, with PDF reading, on X11. Also a single self-contained binary. Dialogs stay inside the main window.
Android Touch, pen, on-screen keyboard and international text input, and it uses Android's own file picker so it can open documents from wherever you keep them. Emulator-verified only. No PDF reading.
In a web browser The whole Writer runs as a web page — editing, formatting, undo, clipboard where the browser allows it, and opening and saving through the browser's own file picker and downloads. No PDF reading.

Your documents

  • No account, no cloud, no sign-in. Files stay where you put them.
  • Documents are saved in ordinary formats other software can open.
  • No telemetry.

Keep a copy of anything important

This is preview software. It reads formats it does not fully support and will tell you what it approximated, but a round-trip through any editor can lose detail — and the file-reading code has not had a security review. Work on copies, not originals.
