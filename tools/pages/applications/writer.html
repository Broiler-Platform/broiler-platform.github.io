App

Broiler Writer

A word processor that opens the documents you already have, formats them the way you expect, and can show you exactly what formatting is where.

Windows Linux Android · emulator-tested In a browser · paused Preview download

The files it opens

FormatOpenSave
DOCX .docxYesYesText, formatting, lists, pictures — including ones the text wraps around — and the document's headers and footers. Tables open as real tables and are saved back as tables.
Rich Text .rtfYesYesThe best-documented format here; the reader never fails on a malformed file.
HTMLYesYesUses the same HTML engine as the browser.
MarkdownYesYesA safe CommonMark-style subset.
OpenDocument .odtYesYesOn every platform, tables included.
PDFRead only—Windows and Linux only. Text and pictures are shown, and a password-protected file asks for its password. You can save what you opened in any of the formats above, but not back to PDF. Deliberately switched off elsewhere until it has been reviewed further.

What it does

  • New, open, save and save-as
  • Bold, italic, underline, strikethrough
  • Choose fonts and sizes through a font dialog
  • Text and background colour
  • Align left, centre, right, or justify
  • Bullet and numbered lists
  • Indent and outdent
  • Clear formatting
  • Insert pictures
  • Insert a page break
  • Zoom from 25 % to 400 % without changing the document
  • Follow web and email links in a document, on Windows and Linux
  • Undo and redo
  • Cut, copy, paste, select all
  • Asks whether to save, discard or cancel before unsaved changes are lost
  • Notes on what it had to approximate when opening a file
  • A document toolbar and a status line

Reveal codes

The feature old WordPerfect users still miss. Turn on Formatting Codes and a second pane shows the document as a stream of tokens — where bold starts and stops, where a paragraph break really is, which tab is doing the indenting — kept in sync with the page as you type.

When a document formats strangely, this is the difference between guessing and looking.

You can select a code and delete it, which is often the fastest way to fix a document that came from somewhere else and behaves oddly.

Dialogs that behave like real windows

On Windows, Open, Save As, Insert Picture and Font are genuine top-level windows. You can drag one onto a second monitor, the window manager orders it like any other window, and closing a dialog never closes the Writer.

On Linux, Android and in the browser they stay inside the main window instead. That is the documented fallback, not a bug: the app asks the system whether it can have a real window, and does the sensible thing when it can't.

What it doesn't do yet

  • Adding a new table, header or footer — the ones already in a file are shown, but there is no command to create one
  • Footnotes and endnotes
  • Track changes or comments
  • Spell check or grammar check
  • Mail merge
  • Styles as a managed, reusable set
  • Printing
  • Saving to PDF
  • On Linux, closing the window from its title bar does not ask about unsaved changes — use File → Exit

On each platform

PlatformWhat you get
Windows The most complete version: hardware-accelerated drawing, real system windows for dialogs, and PDF reading. Compiles to a single 9.2 MB file that runs with no .NET installed.
Linux Same features, with PDF reading, on X11. Also a single self-contained binary. Dialogs stay inside the main window, and closing from the window's title bar skips the unsaved-changes question.
Android Touch, pen, on-screen keyboard and international text input, and it uses Android's own file picker so it can open documents from wherever you keep them. The preview includes an Android package you can install by hand, but the project has verified the app on an emulator only — not yet on a physical phone. No PDF reading.
In a web browser Paused. The Writer was built to run as a web page — editing, formatting, undo, and opening and saving through the browser's own file picker. Since 14 September its automatic build has been switched off while that version is moved onto the platform's new packages, and no preview includes it. Treat it as not currently available.

Your documents

  • No account, no cloud, no sign-in. Files stay where you put them.
  • The only network use is opening a link you click, in your own web browser or mail program.
  • Documents are saved in ordinary formats other software can open.
  • No telemetry.

Keep a copy of anything important

This is preview software. It reads formats it does not fully support and will tell you what it approximated, but a round-trip through any editor can lose detail — and the file-reading code has not had a security review. Work on copies, not originals.

Getting it

For developers

Four heads over a shared core, NativeAOT desktop publishes with zero trim warnings, a codec policy asserted by tests, and components consumed as NuGet packages — a plain git clone builds it.
