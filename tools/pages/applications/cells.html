App

Broiler Cells

The newest and smallest app in the family: a grid you can type into, with every cell named by its column and row, saved as a plain CSV file. A spreadsheet without the formulas — deliberately.

Windows Preview download

What it does

Cells was built in three small, numbered versions — show cells, edit cells, then label rows and columns — and all three are implemented, plus a menu bar and CSV files on top. That is where its roadmap ends.

  • A sheet of up to 100 rows by 100 columns, labelled A–CV and 1–100
  • The address of the cell you are on, such as A1 or B2, always shown
  • Type to replace a cell, or double-click or press F2 to edit it in place; Enter keeps the change, Escape drops it
  • Move with the arrow keys, Tab, Page Up and Page Down, the mouse wheel and the scrollbars
  • Click a row number or column letter to select it; Shift and Ctrl extend the selection, and dragging selects a range or a rectangle of cells
  • Drag the edge of a row or column to resize it; double-click a column edge to fit its contents
  • New, Open, Save and Save as for CSV files, with the usual keyboard shortcuts
  • Text with commas, quotes and several lines in one cell survives the round trip through CSV

What it doesn't do

  • Formulas, sums or any calculation — cells hold text
  • Formatting, charts, several sheets, or spreadsheet formats other than CSV
  • Sheets larger than 100 × 100
  • Run anywhere but Windows

The same grid control is meant to be reusable — for example so the Writer could one day embed a small table. The project calls that a design consideration, not a promise.

Getting it

A preview you can download

Broiler Cells preview builds are available on GitHub as early previews for evaluation and testing.

  • Available for Windows as an unzip-and-run package.
  • It is not code-signed, so Windows SmartScreen may ask before the first start.
  • You can also run the web edition via the in-browser Cell preview.

For developers

Two platform-neutral libraries — the sheet model and CSV serializer (Broiler.Cells.Core) and the reusable cell control (Broiler.Cells.Controls) — and a Windows head, on Broiler.UI, Broiler.Hosting and the Direct2D backend. CSV goes through Broiler.Documents.Csv. Every Broiler component comes from nuget.org.
