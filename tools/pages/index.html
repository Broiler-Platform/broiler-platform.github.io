Open source · Early preview

Everyday apps, built from scratch.

Broiler is a web browser, a word processor, a document viewer, a code editor and — still in development — a mail app, all built on one platform written from the ground up in .NET. Same look, same behaviour, whether you run them on Windows, Linux or Android.

The apps

What you can actually run

Real applications, not demos. They share one toolkit, one renderer and one set of file handling — so a habit you learn in one carries into the next. Three of them can now be downloaded as early previews.

Broiler Browser

Browse the web: type an address, follow links, go back and forward, fill in forms, keep favourites. It renders real pages — Wikipedia, GitHub, MDN — with its own engine, not a copy of someone else's.

Broiler Writer

Write and format documents, and open the files you already have — DOCX, ODT, RTF, HTML and Markdown, plus PDFs for reading. Includes a reveal-codes view that shows exactly what formatting is where.

Broiler Plate

A viewer: open a document or a picture and look at it, nothing else. Reads the same files as the Writer — plus PNG, JPEG, GIF, BMP, TIFF and WebP pictures.

Broiler Code

A C# editor with syntax colouring, live error checking and a build button. It also carries a review workspace that tracks, file by file, what a person has actually read.

Where it stands

Honest answer: you can try it, not rely on it

Broiler is an early preview. You can now download preview builds of the Browser and the Writer (Windows, Linux and Android) and of Plate (Windows) from GitHub. They are for trying out, not for real work: the desktop files are not code-signed, and no person has yet reviewed the code behind them — the safety review the project set as its own bar.

Code and Mail have no preview yet. If you are a developer you can build them yourself. If you are not, the useful thing to do is try a preview on something that doesn't matter, watch the project — or help fund it.

Why bother

Why build all this from scratch?

No borrowed engine inside

Most alternative browsers are a shell around Chromium. Broiler's page engine, layout, text rendering and JavaScript are its own code — so it is genuinely a different implementation, not a reskin.

One app, many machines

The same application code runs on Windows, Linux and Android. Only a thin layer at the bottom changes, so behaviour does not drift between them.

Small and self-contained

The desktop Writer compiles to a single 9.2 MB file that runs with nothing else installed — no runtime to download first, no folder of 162 files. Its Windows preview download is a 5 MB zip.

Readable, checkable code

It is written in managed .NET rather than C++, and every safety-relevant boundary is written down. The project publishes what it has not verified as plainly as what it has.

Free, and free to fork

Apache-2.0. Every part of it is public, including the parts that are unfinished, the failing tests and the open bugs.

Your files stay yours

Documents open and save in the formats you already use. There is no Broiler account, no cloud and no telemetry in any of the apps — the mail app signs in to your own mail server, never to Broiler.

Under the hood

Built out of parts, each of which does one job

The apps are assembled from a set of independent building blocks. You never need to think about them — but they are why one browser, one word processor and one editor can share so much. (Yes, the project's mascot is a chicken. A broiler is a chicken.)

Questions

The things people ask first

Is it free?

Yes, and it always will be. Broiler is open source under the Apache 2.0 licence. There is no paid edition, no subscription and no account.

Can I install it today?

Partly. Preview builds of the Browser, Writer and Plate are on GitHub: unzip-and-run files for Windows and Linux, and an Android package you install by hand. There is no installer, the desktop files are not code-signed, and the code behind them has not been through human review yet — so use them on copies of things that don't matter. What you can download →

Will it replace Chrome or Word?

Not today, and that is not a near-term goal. Broiler renders many real websites well and opens most everyday documents, but a mature browser and a mature word processor represent decades of work. This is a preview of a genuine alternative implementation, not a finished product.

Does it send anything anywhere?

The apps have no Broiler account, no telemetry and no sign-in. The browser obviously fetches the pages you ask it for, and the mail app talks to the mail server you set up. On Android, only the Browser is allowed to use the network at all, and unencrypted connections are switched off in both Android apps.

Who makes it?

A small project run by one maintainer, with a lot of the code written by AI tools under their direction — which the project states openly, and backs with a review system that records what a human has actually read. How it is made →

How can I help?

Try a preview and report what breaks, or sponsor the project — the maintainer pays for the AI inference and the testing time personally, so funding directly moves it along.

Are you a developer?

Everything is on GitHub, and the platform ships as reusable .NET packages: a layout engine, a UI toolkit, image codecs, document codecs, a JavaScript engine. Start with the developer overview — it maps the whole thing in one page.
