Broiler.Media

Decode-first media: image, audio and video decoding, format probing and codec selection, behind small abstraction assemblies with one concrete implementation per media kind. Rendering, windowing, networking and HTML media-element behaviour deliberately live outside it.

0.1.0-preview.1 8 packages Apache-2.0 Untrusted binary input

Additional audio codecs — MP3, AAC, Vorbis, Opus, FLAC — and non-Media-Foundation video providers are future work. The stack reports a deterministic capability error for a format it does not support, rather than a misleading placeholder.

Explicit codec selection, no hidden globals

There is no process-wide mutable Current singleton and no module-initializer side effect. The application composition root builds one immutable catalog and reuses it. Selection is content-probe first: MIME type, file extension and URL are hints only.

selecting and using a codec
var catalog = new MediaCodecCatalog(ManagedImageCodecs.CreateCodecs());
using var input = new MediaInput(stream, new MediaSourceHints(mimeType: "image/png"));

MediaCodecMatch? match = await catalog.SelectAsync(MediaKind.Image, input);
if (match?.Codec is ImageCodec codec)
    ImageSequence decoded = await codec.DecodeAsync(input);

Graphics decodes images through an injected catalog via Broiler.Graphics.BImageCodecs.Use(...) — Graphics references only Broiler.Media.Image, never the implementation. Browser and application playback — the <audio>/<video> playback clock, transport and element state machine — lives in the HTML and application components, never here.

All media is untrusted input

Bounded by contract, not by hope

Decoders enforce configurable MediaLimits — encoded byte count, image and video dimensions, pixel and frame counts, audio channels, sample rate and duration, probe bytes and probe time, queued and decoded memory — and use checked arithmetic for dimensions, strides and allocation sizes.

Malformed data produces a bounded MediaException carrying a MediaError (codec id and byte offset where safe). Never unbounded allocation, hangs, silent partial success, or arbitrary exception leakage.

That is a design contract, not an audit result: no fuzzing campaign, dependency scan or independent security audit is recorded for this revision.

Building and testing

Broiler.Graphics is a submodule here, but only Broiler.Media.Video.MediaFoundation and its test runner reference it — so the cross-platform build and all seven cross-platform packages work in a checkout without it. Building the -Windows configurations does require it.

build & test
git clone --recurse-submodules https://github.com/Broiler-Platform/Broiler.Media.git
dotnet build Broiler.Media.slnx -c Release-Linux
./eng/run-tests.sh

Tests are self-hosted console runners rather than a test framework, so there is nothing for dotnet test to discover.
