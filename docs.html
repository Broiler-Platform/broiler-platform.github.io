Documentation index

Where everything is written down

Broiler's documentation lives beside the code it describes: cross-component work in the aggregate repository, and design, API, conformance and implementation records with the component that owns them. This index links the current ones.

Two repositories, one rule

The aggregate MaiRat/Broiler repository holds cross-component architecture, integration contracts and work that must be coordinated across more than one component. Everything else belongs to a component repository under Broiler-Platform. A root document links to a component record rather than copying its checklist.
